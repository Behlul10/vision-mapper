## Monthly Summaries

### 📅 August / September (Phase 1: Inception)
**Focus:** Initial Setup & Exploration
We kicked off the project by setting up the repository and diving deep into MediaPipe's architecture. The main goal was to understand how to access the webcam stream and process it through the MediaPipe pipeline. By the end of September, we had a basic understanding of the "Vision" component but hadn't yet started on the 3D integration.

### 📅 October / November (Phase 2: The "Gap")
**Focus:** Research & Academic Blockers
This period was characterized by heavy research into Three.js and vector mathematics to understand how to map 2D landmarks to 3D space. Progress on the code was slower due to midterms and other academic commitments. However, this "quiet" period was crucial for planning the architecture of the final demo. We identified the need for a custom Vite setup to handle the complex dependencies.

### 📅 December (Phase 3: The Sprint)
**Focus:** Implementation & Delivery
Returning to the code with a clear plan, we overcame significant configuration hurdles (Vite/TypeScript setup) in early December. In a final sprint, we successfully integrated all three core components:
1.  **Vision**: Real-time pose tracking.
2.  **Scene**: A smooth, mirrored 3D skeleton.
3.  **UI**: Capture and Copy functionality.
The project concluded with a fully functional demo and comprehensive documentation.

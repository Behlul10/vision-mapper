# Documents Overview

This folder groups the planning and presentation artifacts that support the Vision Mapper roadmap. Use these references when preparing demos, writing status updates, or aligning on scope.

## Files
- `project-timeline.md` – semester plan with week-by-week targets, milestone checklists, and presentation deliverables.
- `presentation-1 copy.md` & `presentation-2.md` – slide outlines and talking points for the two most recent presentation iterations. Duplicate the latest file when starting a new revision so prior drafts stay intact.

## Subdirectories
- `documentation-and-iterations/` – scratch space for exploratory write-ups, alternate slide decks, and any archived notes that no longer belong in the top level. Treat this area as a staging ground before promoting artifacts upward.

## Usage Tips
- Update the timeline first when priorities change; other documents should reference it.
- Keep presentation files short-living and versioned—prefer copying forward instead of editing in place.
- When adding new docs, include a short blurb here so contributors can find them quickly.
